# 15112-project SLIMES
/1. Short description:
    Welcome to game SLIMES!
    Remove all the slimes in limited time to win the game!

/2. How to run the project:
    run the app.py file.

/3. Which libraries you're using:
   from PIL import Image

/4.shortcut commands：click button / slimes
    [RULES]
    In this game, you can either mix or remove slimes according to the rules. There are six slimes with different colors in the game.

    MIX: Two slimes in the Slime Wheel can be mixed into one that between them.
    REMOVE: You can remove two slimes with the same color.

    Different Slimes represent different values. The more slimes you generate and remove, the more scores you will get!

    [MODE]
    In standard mode, there are three different levels you can choose. Each level will generate game map automatically. Players need to remove all the slimes in limited time.

    # In infinite mode, players can't see the color of slimes until they click them. Players need to remove as many slimes as possible in limited time.

    When playing, players can use 'Hint', 'Undo', 'Redo', and so on to solve the game quicker.

    When finishing the game, players will see the score and you can decide whether to play the map again.

    Now, enjoy the game!
